# Minuto

Lokale macOS-App zur Zeiterfassung. Minuto speichert Daten ausschließlich auf dem Mac und unterstützt Timer, manuelle Einträge, Stammdaten, Abrechnungstickets, Notizen, Im- und Export sowie Übersichten.

## Entwicklung

Voraussetzungen: macOS, Xcode Command Line Tools und Node.js.

```bash
./build.sh
```

Die Anwendung speichert Nutzerdaten außerhalb des Repositorys unter `~/Library/Application Support/Kundenzeit/`.
